## DEV / Medium opening

**Title:** Give coding agents a project memory you can inspect

A long agent transcript is not the same thing as useful project memory. The decisions, reasons, tool outcomes, failures, and changed files matter; replaying every old message usually does not.

Qarinah's new project-memory workflow initializes a local evidence ledger, SQLite search index, relationship graph, readable decision and flow records, and a static dashboard. For each new task it retrieves a bounded cited pack instead of treating the complete archive as the prompt.
