## Product Hunt update

**Headline:** One memory system for every Git worktree

**Description:** Qarinah gives every checkout its own evidence-linked project memory and groups initialized sibling worktrees in one local context graph. Coding agents retrieve the right branch, commit, files, decisions, outcomes, and hashes without sharing one writable ledger or replaying the whole project history. Apache-2.0, local-first, with Codex, Claude Code, Cursor, Kimi, Antigravity, CLI, and MCP paths.

## DevHunt
