# Paper continuation plan

Working title: **Qarinah: Evidence-Linked Temporal Memory for Cross-Agent Software Engineering**

Target framing: Qarinah is an evidence and handoff system around strong retrieval, not a claim to have invented a ranking algorithm better than BM25.

## Before final execution

1. Obtain two independent, blinded label sets for the 49-case relevance census; compute agreement and Cohen's kappa before adjudication.
2. Resolve exact provider model/runtime identifiers and preserve CLI/SDK versions.
3. Run four non-final pilot tasks under the four frozen handoff conditions and the pilot budget ceiling.
4. Verify identical repository snapshots, equal Qarinah/summary handoff budgets, randomized condition order, provider usage capture, and disabled native session resume.
5. Freeze any necessary amendment before observing final outcomes; otherwise stop changing Qarinah.

## Final evaluation

- Run retrieval/ranking/temporal evaluation once on all 387 memory-eligible tasks.
- Run abstention once on the separate 20 no-memory controls.
- Run the paired 40-task coding-agent study once through the official container evaluator.
- Report all outcomes, including negative and mixed findings, with repository-clustered uncertainty.

## Paper contribution structure

1. Evidence-linked temporal project memory for coding agents.
2. Static and online retrieval over real repository histories.
3. Conservative evidence acceptance plus adversarial authority, retention, conflict, supersession, and temporal tests.
4. Paired cross-agent handoff evaluation measuring task success, repeated work, context, cost, citations, and invalid-evidence exposure.

The SANER 2027 Agentic AI4SE call explicitly includes memory, retrieval, multi-agent workflows, benchmarks, cost, reproducibility, safety, and governance. It uses double-anonymous review, allows 10 content pages plus two reference pages, and lists a mandatory abstract deadline of 2026-10-19 and paper deadline of 2026-10-23 (AoE): <https://conf.researchr.org/track/saner-2027/saner-2027-agentic-ai4se-track>.
