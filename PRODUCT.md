# Product

## Register

brand

## Users

Developers and teams using Codex, Claude Code, command-line agents, and compatible MCP clients across real software projects. They need the next coding session to recover relevant decisions and evidence without replaying an entire project history.

## Product Purpose

Qarinah is local, cross-editor project memory for coding agents. It records permitted project events and explicit decisions, preserves their source identities in a verifiable ledger and graph, and compiles a small cited context pack for the current task. Success means less repeated context, visible provenance, portable project memory, and a clear failure when supporting evidence is absent.

## Brand Personality

Direct, technical, and accountable. The voice is confident because claims are linked to reproducible evidence, not because the interface exaggerates.

## Anti-references

Avoid generic AI assistant imagery, vague memory-cloud language, dense enterprise dashboards, oversized marketing headlines that obscure the proof, unsupported universal claims, and decorative benchmark numbers without a direct path to methodology.

## Design Principles

1. Lead with the result, then make the evidence one click away.
2. Make cross-editor portability obvious without implying hidden transcript access.
3. Use plain language before ratios or implementation terminology.
4. Keep installation visible and copyable in the first viewport.
5. Let the Qarinah mark, GitHub-like palette, and cited proof carry the identity.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast, keyboard operation, visible focus states, semantic headings and landmarks, reduced-motion support, readable line lengths, and layouts that remain clear at 200% zoom and on narrow screens.
