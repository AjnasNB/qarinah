# Code of conduct

Qarinah is a technical community where contributors must be treated with respect.

## Expected behavior

- Discuss code and evidence, not personal attributes.
- Give specific, reproducible, and constructive feedback.
- Respect privacy, security disclosures, and contributor boundaries.
- Avoid harassment, discrimination, threats, spam, and deliberate disruption.

## Enforcement

Maintainers may edit or remove abusive content, restrict participation, or ban repeated violations. Report conduct concerns privately to the repository maintainers. Security vulnerabilities belong in the private process described by SECURITY.md.

Enforcement decisions should be proportionate, documented privately, and avoid exposing reporters or affected people unnecessarily.
